# Security policy

## Report a vulnerability

Do not report a suspected vulnerability in a public issue, pull request, or discussion.
Use [GitHub private vulnerability reporting](https://github.com/daniel-kindl/tangopad/security/advisories/new).

Include this information:

- The Tangopad version, from **Help > About Tangopad**, or the source commit.
- The OS, the CPU architecture, and the package format.
- The steps that cause the problem, and the result that you expected.
- The effect that you observed.

Remove private document text, paths, and secrets from logs and screenshots.

## Disclosure

The maintainers coordinate the correction and the advisory with the reporter in private.
Do not publish the details before the advisory is public.
The [release notes workflow](docs/release-notes.md) describes how a public security correction appears in the changelog.
