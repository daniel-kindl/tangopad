Tangopad edits one local document at a time. It uses UTF-8.
Editing and preview work offline. Requested update checks contact GitHub.
Document preview does not fetch linked resources.

The guide is ordinary Markdown. Use your viewer's page search or clone the repository to search it offline.
Developer details are in the [developer guide](../development.md).
