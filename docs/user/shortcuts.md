# Keyboard shortcuts

These are the current application gestures. Native interaction still needs release-candidate review on each platform.
Menu labels show platform-specific gestures. The source editor must have focus for editor operations.

| Action | Windows and Linux | macOS |
| --- | --- | --- |
| New | Ctrl+N | Command+N |
| Open | Ctrl+O | Command+O |
| Save | Ctrl+S | Command+S |
| Save As | Ctrl+Shift+S | Command+Shift+S |
| Reload from Disk | F5 | Command+R |
| Undo | Ctrl+Z | Command+Z |
| Redo | Ctrl+Y | Command+Shift+Z |
| Cut | Ctrl+X | Command+X |
| Copy | Ctrl+C | Command+C |
| Paste | Ctrl+V | Command+V |
| Select All | Ctrl+A | Command+A |
| Find | Ctrl+F | Command+F |
| Replace | Ctrl+H | Command+H |
| Go To Line | Ctrl+G | Command+G |
| Zoom In | Ctrl+Plus or Ctrl+keypad Add | Command+Plus or Command+keypad Add |
| Zoom Out | Ctrl+Minus or Ctrl+keypad Subtract | Command+Minus or Command+keypad Subtract |
| Reset Zoom | Ctrl+0 or Ctrl+keypad 0 | Command+0 or Command+keypad 0 |

Zoom In also accepts Shift with the Plus gesture.
Plus and minus key positions vary with the keyboard layout.
Use **View > Zoom In**, **Zoom Out**, or **Reset Zoom** if the keys are unavailable.

| Context | Key | Result |
| --- | --- | --- |
| Search field | Enter | Find next |
| Search field | Shift+Enter | Find previous |
| Search panel | Escape | Close search and return focus to source |
| Go To Line | Enter | Confirm line number |
| Go To Line | Escape | Cancel navigation |
| Controls | Tab, Shift+Tab | Move focus forward or backward |

Word Wrap, line numbers, preview, and appearance are available through controls or menus.
No dedicated application shortcut is assigned to those actions.
